# Курс для iPad

Сайт: https://quand.github.io/course-irina/

- Google Drive: основной адрес сайта.
- Яндекс Диск: https://quand.github.io/course-irina/yandex/ (ссылки на видео пока не заполнены).

Видео хранятся отдельно в Google Drive. Этот репозиторий содержит только
статический сайт. Отметки хранятся на устройстве; перенос — через экспорт/импорт в меню курса.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`. Изменения в этой ветке
автоматически публикуются. Файл `.nojekyll` отключает обработку Jekyll.

Для обновления скопируйте содержимое `site/` исходного проекта:
`index.html`, `app.js`, `app.css`, `videos.js`, `manifest.webmanifest`,
папки `icons/` и `yandex/`. Не добавляйте MP4-файлы и папки с видео.

## iPad

Откройте сайт в Safari → «Поделиться» → «На экран Домой».
Видео требуют интернета. Если плеер Google не работает, можно открыть
папку курса или скачать файл кнопками в окне занятия.

## Экран входа

На обеих версиях включён общий экран с фиксированными логином и паролем.
Проверка выполняется в браузере; это не защита публичных файлов и ссылок.
Конфигурация в `auth-config.js` содержит логин и SHA-256 хеш пароля.
При смене пароля измените также `version` и параметр `?v` у этого скрипта
в обеих HTML-страницах. Сам пароль в репозитории не хранится.

Вход можно запомнить на 30 дней. «Выйти» сохраняет отметки прохождения.
При обновлении сайта также копируйте `auth.js` и `auth-config.js`.
